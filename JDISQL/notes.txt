UNION ALL

Stacks all rows from two or more queries on top of each other.
Every row is included, even if duplicates exist across the queries.
Fastest set operator — no deduplication step.

SELECT column_1,
       column_2
FROM table_a
UNION ALL
SELECT column_1,
       column_2
FROM table_b;

Removes duplicate rows from the result.
Use when the same row may appear across tables and each unique row should appear only once.
Slower than UNION ALL because of the deduplication step.
SELECT column_1,
       column_2
FROM table_a
UNION DISTINCT
SELECT column_1,
       column_2
FROM table_b;

Column Compatibility

All SELECT statements in a set operator must return the same number of columns.
Columns must have compatible data types in the same order.
Column names do not need to match — the result uses names from the first SELECT.
Mismatched counts or incompatible types produce an error.

--Write a LEFT JOIN with countries on the left and the cities on the right, joining on country code.
--In the SELECT statement of your join, include country names as country, and count the cities in each country, aliased as cities_num
--Sort by cities_num (descending), and country (ascending), limiting to the first nine records.
-- Find top nine countries with the most cities

SELECT countries.name AS country, COUNT(*) AS cities_num
FROM countries
LEFT JOIN cities
ON countries.code = cities.country_code
GROUP BY country
ORDER BY cities_num DESC , country ASC
LIMIT 9;

--Complete the subquery to return a result equivalent to your LEFT JOIN, counting all cities in the cities table as cities_num.
--Use the WHERE clause to enable the correct country codes to be matched in the cities and countries columns.
SELECT countries.name AS country,
-- Subquery that provides the count of cities
  (SELECT COUNT(*)
   FROM cities
   WHERE cities.country_code = countries.code) AS cities_num
FROM countries
ORDER BY cities_num DESC, country
LIMIT 9;

--Select local_name from countries, with the aliased lang_num from your subquery (which has been nested and aliased for you as sub).
--Use WHERE to match the code field from countries and sub.
-- Select local_name and lang_num from appropriate tables

SELECT local_name,sub.lang_num
FROM countries,
  (SELECT code, COUNT(*) AS lang_num
  FROM languages
  GROUP BY code) AS sub
-- Where codes match
WHERE countries.code= sub.code
ORDER BY lang_num DESC;
